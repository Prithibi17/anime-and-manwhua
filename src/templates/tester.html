🎬 1. Anime Video & Built-in Player API
GET /api/anime/player

Returns the complete built-in player URL and ready-to-use <iframe> embed snippet featuring the horizontal hover volume slider, 10s skip buttons, AniSkip button at bottom: 85px, and yellow timeline markers.

Query Params: id (AniList ID, req), episode (default 1), type (sub/dub), key (API Key)
GET /api/anime/stream

Extracts direct streams (DatSaV MP4 & Vidplay HLS) with pre-configured CORS proxy links (/proxy_mp4 and /proxy_m3u8), WebVTT subtitles, and AniSkip timestamps.

GET /api/anime/episodes/{anime_id}

Returns anime details, banner, HD poster, and full catalog of episodes with direct player_url and iframe_embed links for each episode.

📖 2. Manga, Manhwa & Manhua API
GET /api/manga/search

Search across Vortex Scans, Toraka, MangaDex, and AniList. Every result is automatically enriched with official AniList high-definition posters and proxied covers.

Query Params: q (keyword), type (all/manhwa/manga/manhua), source (all/vortex/toraka/mangadex), key
GET /api/manga/info/{slug}

Retrieves synopsis, genres, official HD poster, and full chapter list with direct web reader URLs and lock statuses (is_locked).

GET /api/manga/chapter/{chapter_id}

Returns all page images for reading. Images are pre-routed through /proxy_image so they render in any browser or app without CORS or anti-hotlink blocks. Also provides a standalone reader_url and iframe_embed.

GET /api/anime/releases/{anime_id} NEW

Tracks exact count of released episodes, airing status (is_airing), next episode countdown, official AniList HD posters & banners, and full episode list with pre-built direct player links and iframe embeds.

GET /api/manga/releases/{slug}?include_pages=true NEW

Tracks total released chapters count, latest released chapter, highest unlocked chapter, official AniList HD covers, and returns full panel images pre-wrapped in CORS-safe /proxy_image links for instant reader rendering.

GET /api/releases?type=anime|manga&id=... UNIFIED HUB

Unified router for AI agents and apps to query release tracking, counts, posters, panels, and player embeds for either anime or manga via a single clean endpoint.
